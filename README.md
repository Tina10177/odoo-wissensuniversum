# Odoo-Wissensuniversum

**Ein strukturierter öffentlicher Einstieg in mein Odoo-Wissensuniversum – mit Fokus auf Prozessverständnis, Systemlogik und praxisnahe Orientierung.**

Dieses Repository ist die deutschsprachige öffentliche Version eines fortlaufend entstehenden Wissensraums rund um Odoo.

Im Zentrum stehen nicht nur einzelne Funktionen, sondern vor allem Zusammenhänge: Prozesse, Rollen, Systemlogik, typische Missverständnisse und die Frage, wie Odoo im praktischen Unternehmenskontext besser verstanden werden kann.

## Aktuell im Fokus
- Prozessverständnis in Odoo
- Zusammenhänge zwischen Vertrieb, Einkauf, Lager, Buchhaltung und Produktion
- Rollenverständnis von Endanwendern, Key Usern und Beratern
- Praxisnahe Einordnung typischer Fragen und Missverständnisse
